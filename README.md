# ComfyUI_SaveImageCopy
I have added features to the existing official SaveImage node, including viewing the image in full screen, opening the folder, and creating backups.
## Functions
- basic : Essentially, it functions the same as the original 'saveimage' node. It saves images to the path specified by 'filename_prefix'.
- backup : An additional backup copy of the image is saved to the specified 'path'.
- open folder : Open the folder containing the image that was just saved.
- full screen preview : Clicking a node's preview image expands it to full screen.
